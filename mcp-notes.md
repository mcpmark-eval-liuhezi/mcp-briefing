## 1. One-line definition (exact official wording)

> MCP (Model Context Protocol) is an open-source standard for connecting AI applications to external systems.

— Official MCP documentation, "What is the Model Context Protocol (MCP)?"

## 2. What MCP is for — key facts

1. **It standardizes how AI apps reach the outside world.** Using MCP, AI applications like Claude or ChatGPT can connect to data sources (e.g. local files, databases), tools (e.g. search engines, calculators) and workflows (e.g. specialized prompts) — enabling them to access key information and perform tasks.
   Source: [Official MCP docs — Intro](https://modelcontextprotocol.io/docs/2026-07-28/getting-started/intro)

2. **The mental model: "USB-C for AI applications."** Just as USB-C provides a standardized way to connect electronic devices, MCP provides a standardized way to connect AI applications to external systems — one standard connector instead of N bespoke integrations.
   Source: [Official MCP docs — Intro](https://modelcontextprotocol.io/docs/2026-07-28/getting-started/intro)

3. **It benefits every layer of the ecosystem.** For developers, MCP reduces development time and complexity when building or integrating with AI applications or agents; for the applications themselves, it provides an ecosystem of data sources, tools and apps; for end-users, it results in more capable agents that can access data and take actions on the user's behalf.
   Source: [Official MCP docs — Intro](https://modelcontextprotocol.io/docs/2026-07-28/getting-started/intro)

4. **It has broad, multi-vendor ecosystem support.** MCP is an open protocol supported across a wide range of clients and servers — AI assistants like Claude and ChatGPT, development tools like Visual Studio Code, Cursor, MCPJam, and many others — so you can build once and integrate everywhere.
   Source: [Official MCP docs — Intro](https://modelcontextprotocol.io/docs/2026-07-28/getting-started/intro)

5. **It's an open standard with real adoption.** MCP was introduced and open-sourced by Anthropic in November 2024, and has since been adopted by major AI providers including OpenAI and Google DeepMind.
   Source: [Anthropic's announcement](https://www.anthropic.com/news/model-context-protocol), [Wikipedia — Model Context Protocol](https://en.wikipedia.org/wiki/Model_Context_Protocol)
