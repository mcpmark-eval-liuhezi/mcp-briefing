## Why these three

- **NetworkChuck** — the most hands-on and production-tilted: Docker-containerized MCP servers, multiple clients, custom server builds, Docker MCP Gateway. Big reach (5.44M subs).
- **Fireship** — the fastest primer: compact concept explanation plus a real TypeScript MCP-server build in ~8 minutes. High reach (4.31M subs) and strong production values.
- **Tina Huang** — the most structured deep-dive: a 26-minute teaching-style walkthrough with quizzes, covering MCP fundamentals through building servers with code and no-code. Practitioner background (ex-Meta data scientist, teaches an MCP section in her AI agents bootcamp).

All three have published dedicated MCP content within roughly the last year (Mar 2025 – Oct 2025) and remain actively uploading as of this week.
